#ddddpp
This project aims to predict a student's final academic grade using **Supervised Machine Learning**. By analyzing variables such as study hours, attendance, and previous scores, the model provides an estimate of future performance. This tool can be used by educators at institutions like **VIT Bhopal** to identify students who may require additional academic support.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** * `Pandas` (Data Manipulation)
    * `Scikit-Learn` (Machine Learning Modeling)
    * `NumPy` (Numerical Calculations)

##dem
* **Predictive Modeling:** Uses Linear Regression to forecast grades.
* **Data Visualization:** Analyzes correlations between lifestyle habits and GPA.
* **Evaluation:** Measures performance using Mean Squared Error (MSE) and R-squared metrics.
